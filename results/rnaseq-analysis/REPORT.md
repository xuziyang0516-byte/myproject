这次分析分别处理 BMDC 与 PBMC，按相同编号配对，保留各自选定的十条通路。最终交付两套图：三列完整 GO/KEGG ORA 图，以及更建议用于论文正文的“三组配对表达热图 + 处理对照上调 ORA”组合图。三组均可显示，但结果不支持强制使三列都显著。

**三列 ORA 的统计含义**

CTRL：CTRL − (Y180 + IMP321)/2；Y180：Y180 − (CTRL + IMP321)/2；IMP321：IMP321 − (CTRL + Y180)/2。这些是配对 DESeq2 模型 `~ subject + group` 中的数值对比，平均发生在模型的 log 表达尺度上，而非简单平均原始 reads。它改变了原来“处理 vs CTRL”的科学问题，不能把两种图的 P 值直接互换。

前景为每个对比的全部显著差异基因，包含上调与下调：基因 BH 校正 P < 0.05 且未收缩 |log2FC| ≥ 1。Count 是前景与完整注释通路的交集基因数，按 Entrez ID 去重；颜色是上尾超几何 ORA 的 BH 校正 P。通路检验对所有大小为 5–1000 的可用 GO/KEGG 基因集计算，然后对三项计划对比的所有检验一起校正，最后才显示选定通路。空心点表示不显著，叉号表示 Count=0，没有用最小点尺寸伪造零计数。

| 数据 | CTRL 显著通路 | Y180 显著通路 | IMP321 显著通路 |
|---|---:|---:|---:|
| BMDC | 5/10 | 4/10 | 1/10 |
| PBMC | 9/10 | 9/10 | 0/10 |

CTRL 的显著富集可以由相对处理组降低的炎症相关基因产生；它不表示 CTRL 的炎症通路被激活。此图显示的是差异相关通路，而不是三组绝对“活性”。三项对比并不独立，也不是三个互不相关的生物学证据。

**建议用于正文的组合图**

`BMDC_paper_recommended` 和 `PBMC_paper_recommended` 左侧展示完整注释通路中所有经过计数筛选、具有非零变异的表达基因，而非只展示旧 Excel 的显著基因。对 VST 进行逐基因 z 标准化，再利用 `~ subject + group` 去除 subject 贡献、保留 group 贡献，展示全部九个配对样本。样本数和配对信息保持可见。该表达图用于描述趋势，平均表达分数不能直接解释为功能激活。

右侧保持科学问题“Y180 vs CTRL”“IMP321 vs CTRL”，Count 为完整通路中的上调 DEG 交集数，颜色为重新计算的 ORA 校正 P。BH 家族包括所有可用通路与这两项计划对比，而不是只校正十条筛选后的通路。这两项上调 ORA 中，BMDC 共 12/20 个单元格显著，PBMC 为 18/20。图的两部分共用同一通路顺序，读者可以同时判断三组表达模式、供体间一致性和处理对对照的统计证据。

主结论应来自完整基因/通路检验；选定通路来自此前对同一数据的分析，因此它们属于筛选后的展示，不能声称是独立验证。即使对完整检验家族进行校正，也不能把两张使用同一批样本的图当成互相独立的实验重复。正式论文仍应结合预设假设、必要的独立实验验证及生物学机制解释。

**数据支持什么，为什么不能靠代码制造三组差异**

| 配对比较 | BMDC 差异基因 | PBMC 差异基因 |
|---|---:|---:|
| Y180 vs CTRL | 445 | 2242 |
| IMP321 vs CTRL | 295 | 786 |
| Y180 vs IMP321 | 2 | 81 |

这些数字使用本次的未收缩 fold change 和显式共同测试背景，不一定等同于旧代码使用收缩 fold change 得到的数字。每组只有三个配对生物学重复。BMDC 中两种处理之间达到指定阈值的差异基因极少，提示响应相似，但“不显著”不能证明两者等效。三列 ORA 中 IMP321 不显著，是“IMP321 相对另外两组平均值”的结果；它不否定 IMP321 相对 CTRL 的作用。P 值大小也不能代替效应大小来比较药效。

**旧代码的问题与本次修正**

1. 普通 ORA 的 P 值属于比较，不是某一组自身的属性。原来两项处理对照 ORA 不能通过加一列或复制数值变成 CTRL/Y180/IMP321 三组统计。
2. 旧 GSEA 图的颜色来自 GSEA，而大小来自阈值定义的上调 DEG 数。GSEA 显著时，这个 DEG Count 仍可能为零，导致统计显著但气泡消失。若继续使用 GSEA，更合理的大小可使用 leading-edge/core-enrichment 基因数，并明确标注 NES 方向，不能称为普通 ORA Count。本次主图使用 ORA，P 与 Count 来自相同前景和背景定义。
3. 原表达气泡图的大小是检出比例，而不是差异基因数。基因在三组都被检出时，大小接近是正常现象。不能人为缩放某组来创造差异。
4. BMDC Sheet4 去重后恰好十个 ID；PBMC Sheet5 去重后恰好十个 ID。重复行没有被当成不同通路。参考图中额外的通路并不自动纳入本次十条选择。
5. BMDC 中 IL-17、TNF、NF-kappa B 等 ID 被错误显示为 PI3K-Akt。按 ID 与正确 Description 修复了标签。GO/KEGG 也按 ID 前缀识别，而非信任部分错误的 Database 字段。
6. PBMC 工作簿包含大量格式化空白行及混入的小鼠基因模块。采用流式读取避免把空白行当数据。完整 ORA 只使用物种对应的官方注释；探索性模块图的跨物种或完全无法匹配的来源行另行记录，保留审计表。
7. 输入矩阵为非负整数，Geneid 不重复。计数预筛选为至少三个样本 count ≥10，BMDC 保留 14855/54532 个基因，PBMC 保留 20693/78894 个。样本与 subject 用列名解析，避免 BMDC/PBMC 原始列顺序不同造成配对错位。基因层面的 independent filtering 被关闭，以保留明确、可复查的 tested-gene 背景；有效 Wald P 值的基因经 Ensembl–Entrez 映射去重后作为 ORA 背景。
8. 本次使用物种对应 org.Hs.eg.db/org.Mm.eg.db 3.20.0 的 GOALL 注释及实际下载、缓存的 KEGG REST 通路基因集。它们与旧代码的 KEGG_2019_Mouse 或 MSigDB KEGG_LEGACY/MEDICUS 不是同一个版本或集合；不应期待旧、新数值完全相同。每项结果的 Universe、DEGTotal、GeneSetSize、Count、原始 P 和校正 P 都已导出。

**探索性模块统计图的用途与限制**

另外保留 `*_three_groups_Pvalue_Count` 图，供比较原来的表达气泡图。其 P 值来自 Excel 选定 UP-DEG 模块平均 gene-wise VST z-score 的配对线性模型，每个组与另外两组均值比较，残差自由度为 4，BH 校正每个数据集十模块×三对比的 30 项检验。Count 是 normalized count ≥50 且在同组至少两个供体中检出的模块基因数，沿用旧表达代码的检出定义；它不是 ORA Count。这里 BMDC 30/30、PBMC 21/30 项达到校正阈值，但模块基因本身来自同一数据的 DEG 选择，存在选择偏倚。因此这些 P 值只能作探索性显示，不应当作独立、确认性的通路显著性证据，更不能替代本次完整 ORA 主结果。

**运行与文件**

所有原始输入和三份旧代码均保持不变，`inputs/manifest.json` 记录 SHA256。新代码与结果位于独立分析目录，原始 Git 仓库没有改动。软件版本和依赖应查看 `results/sessionInfo.txt` 与 `results/software_versions.tsv`；当前验证环境为 R 4.5.0、DESeq2 1.46.0、GO/物种注释库 3.20.0。本次 RNA-seq 工作不修改原仓库记录 R 4.6.1 的 renv.lock。

在当前 Cloud 环境执行：

```bash
bash /workspace/rnaseq-analysis/run_analysis.sh --full-ora
```

该命令从复制的原始输入重新提取选择、生成 QC、执行配对差异分析、绘制探索性模块图、运行完整 ORA 并生成论文组合图。脚本通过 RNASEQ_PROJECT 支持迁移路径。在其他机器上，需要 Python 3、R、DESeq2、AnnotationDbi、GO.db、org.Hs.eg.db、org.Mm.eg.db、ggplot2 和 cowplot；包与注释版本不同可能改变结果。可按 `scripts/install_packages.R` 安装，建议安装到独立分析库，避免改动原项目锁文件。网络下载保留 TLS 验证。

`full_pathway_ora.R` 在缺少注释时会明确记录问题并标记 PARTIAL，不能把缺失结果当成不显著。本次两套数据均已补齐全部十条通路，各 30 项统计，无缺失单元格。`plot_full_ora.R` 统一两张三列主图的颜色尺度；统计表不随绘图调整而变化。

`validate_results.R` 核验配对平衡、通路数量、超几何 P 值、完整 BH 校正家族、模块残差自由度及图文件。交付的 ZIP 不包含大型安装依赖、RDS 中间状态和完整注释库；重新运行完整分析时会重新产生这些输出。ZIP 包含原始文件、代码、PNG/PDF、完整差异结果、ORA 统计及选定通路的映射/表达审计表。
